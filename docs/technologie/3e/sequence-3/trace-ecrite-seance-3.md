## Ce que je dois retenir

### Paramétrer un objet autonome

L'autonomie désigne la capacité d'un objet à se gérer lui-même, selon ses propres règles. Pour qu'un utilisateur qui n'est pas expert règle un objet autonome, le concepteur lui propose une procédure sous forme d'algorithme très simple. Paramétrage initial de la tondeuse : appui de plus de 2 secondes, choix de la langue, vérification de l'installation, hauteur de coupe, jours et horaires, validation.

### Écrire un algorithme

Un algorithme est une suite finie d'instructions précises dans un ordre donné. Pour faire saluer le robot Nao : allumer les yeux, tourner la tête vers la personne, lever le bras, secouer le bras trois fois (répétition), dire « Bonjour », descendre le bras. Une condition (si une personne arrive) permet de choisir entre deux actions.

### S'organiser pour rédiger le manuel

Cinq étapes : bien comprendre qui va utiliser l'objet ; coordonner la rédaction avec un rédacteur et un graphiste ; lister toutes les manières d'utiliser l'objet (installation, programmation, rangement, nettoyage) ; respecter les exigences d'étiquetage ; décider d'un mode de publication (papier, en ligne).

## Les mots à connaître

| Mot | Ce que je dois pouvoir écrire |
|---|---|
| **autonomie** | la capacité d'un objet à se gérer lui-même, selon ses propres règles |
| **paramétrer** | régler les valeurs qui décident du fonctionnement de l'objet : langue, hauteur, horaires |
| **algorithme** | une suite finie d'instructions précises, dans un ordre donné, qui résout un problème |
| **instruction** | une action élémentaire de l'algorithme |

## Les erreurs à ne pas commettre

- Croire qu'un algorithme de manuel sert à faire du code informatique : il montre à l'utilisateur comment programmer l'objet, étape par étape.
- Écrire des instructions vagues (« faire bouger le robot ») : chaque instruction doit être exécutable.
- Penser que seuls les experts peuvent rédiger un manuel : un regard neuf est utile.
