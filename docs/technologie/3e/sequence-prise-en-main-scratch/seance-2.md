## PENDANT — je recherche

### Activité 1 · J'ouvre la mission 00

1. J'ouvre le site de la classe : **numerica-lfh.github.io/Techno**.
2. Je clique sur l'onglet **Missions Scratch**, puis sur [Palier 1 (vert)](../../../missions-scratch/palier-1.md#mission-00).
3. Dans la mission 00, je clique sur **Ouvrir l'exercice** : TurboWarp s'ouvre dans un nouvel onglet.
4. Je repère la scène, la liste des lutins et la zone des scripts.
5. Je clique sur le lutin Chat, puis sur l'onglet **Costumes**, puis sur l'onglet **Sons**.

| Le nombre de lutins |   |

### Activité 2 · Je programme la mission 00

Je suis le pas à pas de la page. Je teste souvent avec le drapeau vert. Si je bloque, j'ouvre les coups de pouce **dans l'ordre** : 1, je réfléchis ; 2, les blocs à utiliser ; 3, le squelette du script.

a\. Combien de fois le chat avance-t-il de 10 pas ? De combien de pas avance-t-il en tout ?

b\. J'enlève le bloc « attendre 0.1 secondes ». Que se passe-t-il ?

c\. Je clique deux fois de suite sur le drapeau vert. Pourquoi le chat repart-il du même endroit ?

### Activité 3 · J'enregistre et j'envoie ma progression

1. Dans TurboWarp : **Fichier**, puis **Enregistrer sur votre ordinateur**. Le fichier .sb3 se range dans le dossier Téléchargements. Je le nomme mission-00-prénom.
2. Sur la page du site, je coche **J'ai réussi la mission 00**.
3. Je fais une capture d'écran de mon script : touche Windows + Maj + S sur Windows, Cmd + Ctrl + Maj + 4 sur Mac.
4. En bas de la page, dans **Où j'en suis** : nom, prénom, classe, dernière mission terminée, je colle ma capture, puis j'envoie.

d\. Je ferme l'onglet de TurboWarp sans enregistrer. Que devient mon programme ?

e\. La séance suivante, comment retrouver mon travail ?

Les missions s'ouvrent dans **TurboWarp**, un éditeur en ligne. Il ne garde rien : avant de fermer, j'**enregistre** mon projet sur l'ordinateur, dans un fichier **.sb3**.

En fin de séance, je remplis « Où j'en suis » avec une **capture d'écran** : le professeur voit ma progression.
