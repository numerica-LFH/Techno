# Séquence 2 — Séance 0 : Qu'est-ce qu'un système d'information ?

*Technologie · 5e · Qu'est-ce qu'un système d'information ?*

## AVANT

Je me connecte à l'espace numérique du lycée. J'y trouve mon emploi du temps, mes notes, le cahier de textes, les documents déposés par mes professeurs. Mes parents y voient mes absences, la vie scolaire y saisit les retards. **Où sont rangées toutes ces informations, et qui les fait circuler ?**

| Mot | Sens attendu |
| --- | --- |
| système d'information | ensemble des ressources qui permettent de collecter, stocker, traiter et diffuser des informations |
| ressource matérielle | le matériel : ordinateurs, serveurs, câbles, commutateurs |
| ressource logicielle | les programmes qui récupèrent, traitent et affichent les données |
