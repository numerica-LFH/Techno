# Séquence 2 — Séance 1 : Stocker et classer les données

*Technologie · 5e · Stocker, classer, retrouver*

## AVANT

Un devoir de deux pages, une photo prise avec un téléphone, un film en haute définition. Trois fichiers, trois tailles qui n'ont rien à voir. **Combien de place prend une information, et comment la retrouver ensuite ?**

| Mot | Sens attendu |
| --- | --- |
| octet | unité de base de la mémoire numérique ; un caractère au clavier occupe environ un octet |
| arborescence | rangement des fichiers en dossiers et sous-dossiers, comme les branches d'un arbre |
| extension | les quelques lettres après le point dans le nom d'un fichier ; elles indiquent son format |
