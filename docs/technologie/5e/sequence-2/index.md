# Séquence 2 — Comprendre l'évolution des systèmes d'information

**5e · fil directeur : Où vont mes données ?**

Chapitre 2 du manuel Nathan, thème 1 : les objets et les systèmes techniques, leurs usages et leurs interactions. Programmation du BO n° 9 du 29 février 2024.

Quatre séances de 40 minutes. Même trame que la séquence 1 : AVANT (question du jour, hypothèses écrites, vocabulaire), PENDANT (activités), APRÈS (trace écrite à compléter, retour sur les hypothèses, question qui ouvre la séance suivante).

## Compétences travaillées

- Décrire le rôle des systèmes d'information dans le partage d'information.
- Recenser des données, les identifier, les classer, les représenter, les stocker, les retrouver dans une arborescence.
- Identifier des règles permettant de sécuriser un environnement numérique.
- Appréhender la responsabilité de chacun dans les dérives.
