# Technologie 4e

Thème directeur de l'année : **la communication et la gestion de l'information**.

## Séquences

### 1. Comment circule l'information

*À venir.*

Réseau local, adresse IP, serveur, protocole. Manipulation sur le réseau du
collège.

### 2. Acquisition et traitement de données

*À venir.*

Un capteur produit une grandeur électrique, un programme la transforme en
information exploitable.

### 3. Objets communicants

*À venir.*

Programmation d'une carte micro:bit ou Arduino, envoi de données, affichage.

### 4. Projet : station de mesure

*À venir.*

Mesurer une grandeur de l'environnement du collège, enregistrer, présenter les
résultats.
