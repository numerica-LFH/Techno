## Ce que je dois retenir

### Juger un jeu

Le jury de la Nuit du Code note quatre critères sur 5 points chacun : la jouabilité (le jeu démarre, se joue et s'arrête sans bogue), la richesse (règles, niveaux, sons), l'originalité et le respect des consignes.

### Mode d'emploi et test croisé

Le mode d'emploi dit en quelques lignes le but du jeu, les commandes, ce qu'il faut éviter et comment on gagne ou on perd. Le test croisé, par une autre équipe qui ne connaît pas le jeu, révèle ce que les auteurs ne voient plus. On en tire des améliorations, en commençant par ce qui empêche de jouer.

## Les mots à connaître

| Mot | Ce que je dois pouvoir écrire |
|---|---|
| **mode d'emploi** | le court texte qui explique le but du jeu, les touches et la façon de gagner |
| **test croisé** | le test d'un jeu par une autre équipe, qui note ce qu'elle constate |
| **critère** | un point précis sur lequel on juge le jeu, comme la jouabilité |
| **amélioration** | une modification décidée à partir des résultats d'un test |

## Les erreurs à ne pas commettre

- Expliquer son jeu à voix haute pendant le test : le jury, lui, n'aura pas l'explication.
- Ajouter des effets avant d'avoir corrigé les bogues.
- Oublier le mode d'emploi : c'est un critère noté.
