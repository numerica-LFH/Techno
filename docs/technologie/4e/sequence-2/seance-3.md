# Séquence 2 — Séance 3 : Bilan, règles d'usage et évaluation

*Technologie · 4e · Bilan de séquence et évaluation*

## AVANT

Trois séances : ce que le système sait de moi, comment les échanges sont sécurisés, quelles traces je laisse et quels droits j'ai dessus. **Quelles règles est-ce que je m'applique, à partir de maintenant ?**

| Mot | Sens attendu |
| --- | --- |
| certificat SSL | chiffrement des échanges avec un site |
| témoin de connexion | fichier déposé sur l'appareil qui permet de reconnaître l'utilisateur |
| donnée personnelle | information qui identifie une personne, directement ou indirectement |
| RGPD | règlement européen de protection des données personnelles |
