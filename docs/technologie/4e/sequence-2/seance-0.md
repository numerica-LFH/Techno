# Séquence 2 — Séance 0 : Ce qu'un système d'information sait de moi

*Technologie · 4e · Le système d'information et mes données*

## AVANT

Je crée un compte sur un site : nom, prénom, date de naissance, adresse électronique. Trois secondes de formulaire. Ces quatre lignes vont vivre bien plus longtemps que ma visite. **Que devient une information une fois que je l'ai donnée ?**

| Mot | Sens attendu |
| --- | --- |
| système d'information | ensemble des ressources matérielles et logicielles qui collectent, stockent, traitent et diffusent des informations |
| donnée personnelle | toute information permettant d'identifier une personne, directement ou indirectement |
| objet communicant | objet technique qui échange des données avec un réseau |
