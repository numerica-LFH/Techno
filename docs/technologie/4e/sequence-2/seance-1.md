# Séquence 2 — Séance 1 : Sécuriser les échanges et les accès

*Technologie · 4e · Certificat SSL, mots de passe, hameçonnage*

## AVANT

J'achète un article en ligne et je saisis un numéro de carte. Entre mon clavier et le serveur du marchand, l'information traverse une dizaine de machines que je ne connais pas. **Comment être certain que cet échange n'est lisible par personne d'autre ?**

| Mot | Sens attendu |
| --- | --- |
| certificat SSL | attestation officielle de sécurité qui chiffre les données échangées avec le site |
| hameçonnage | message imitant un organisme officiel pour obtenir des informations personnelles |
| rançongiciel | logiciel qui chiffre les données et réclame de l'argent pour les rendre |
