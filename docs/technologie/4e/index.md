# Technologie 4e

!!! tip "Espace de travail Drive - 4e"

    [Ouvrir le dossier Drive de la classe de 4e](https://drive.google.com/drive/folders/1n_nDIEDRLOqnzJIO6bx_-qul_7kwFBuJ?usp=sharing)

Thème directeur de l'année : **confort, information et communication**. On regarde des objets qui
communiquent, on comprend comment ils traitent l'information, puis on leur ajoute une fonction.

Sept chapitres, quatre à huit séances de 55 minutes. La progression complète figure sur la page
[Programmation annuelle](../programmation-annuelle.md).

## Chapitre 1. Pourquoi les objets techniques évoluent-ils ?

!!! abstract "Question directrice"

    **Un objet change parce que la technique progresse, ou parce que nos usages changent ?**

    Compétences : T1.1, T1.2 · Thème 1 · 4 séances

    | | Objectif |
    |---|---|
    | **Comprendre** | Ce qui distingue une évolution d'usage d'une évolution technique |
    | **Identifier** | Les six niveaux auxquels un objet peut évoluer |
    | **Analyser** | Les avantages et les inconvénients d'une évolution technologique |
    | **Appliquer** | Rédiger un argumentaire court sur une évolution contestée |
