## Ce que je dois retenir

### Sécuriser un échange

Le certificat SSL chiffre les données échangées avec un site : c'est ce que signale le cadenas à côté de l'adresse. Il ne dit rien de l'honnêteté du site, d'où l'importance de lire le nom de domaine : un site frauduleux peut afficher le cadenas et https.

Un rançongiciel chiffre les données d'un système et réclame de l'argent pour les rendre.

### Sécuriser un accès

Un bon mot de passe est long et mélange des types de caractères. Un mot de passe de quatre chiffres n'offre que 10 000 combinaisons et se découvre vite.

L'hameçonnage ne casse pas le mot de passe, il le demande : l'utilisateur le donne lui-même. Ni le chiffrement ni le mot de passe ne protègent contre cette erreur.

## Les mots à connaître

| Mot | Ce que je dois pouvoir écrire |
|---|---|
| **certificat SSL** | l'attestation officielle de sécurité qui chiffre les données échangées avec le site |
| **hameçonnage** | un message qui imite un organisme officiel pour obtenir des informations personnelles |
| **rançongiciel** | un logiciel qui chiffre les données et réclame de l'argent pour les rendre |

## Les erreurs à ne pas commettre

- Croire que le cadenas garantit que le site est honnête.
- Utiliser le même mot de passe court sur plusieurs services.
- Répondre à un message qui imite une banque ou un service connu et demande des identifiants.
