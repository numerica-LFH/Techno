# Missions Scratch

Un parcours de missions pour apprendre à programmer avec Scratch, pas à pas, de la 5e à la 2nde. Chaque mission montre en vidéo le résultat attendu. L'élève ouvre le fichier d'exercice, programme, compare avec la vidéo puis passe à la suivante.

## Les quatre paliers

| Palier | Classe de départ | Contenu | Missions |
|---|---|---|---|
| [Palier 1 (vert)](palier-1.md) | 5e | Premiers scripts | 00 à A2 (11 missions) |
| [Palier 2 (bleu)](palier-2.md) | 4e | Messages, clones et blocs personnalisés | 21 à A4 (18 missions) |
| [Palier 3 (orange)](palier-3.md) | 3e | Variables, capteurs et jeux | 41 à A6 (18 missions) |
| [Palier 4 (violet)](palier-4.md) | 2de | Procédures, algorithmes et passage à Python | 61 à A8 (10 missions) |

Chaque classe commence à son palier. Un élève qui a terminé passe au palier suivant : le parcours continue d'une année sur l'autre jusqu'en 2nde.

Les missions numérotées 01 à 68 reprennent les vidéos Canopé. Les missions A1 à A8 sont des ateliers plus longs : mélodie, dialogue, labyrinthe, polygones, tir à l'arc, premier jeu, passage à Python et projet personnel.

## Une mission, pas à pas

1. Je regarde la vidéo : c'est le résultat que mon programme doit produire.
2. Je clique sur **Ouvrir l'exercice**. Le projet s'ouvre dans TurboWarp, un éditeur en ligne qui fonctionne comme Scratch 3, sans compte. Les lutins et les décors sont déjà en place.
3. Je lis la consigne : elle est sur la page et dans un commentaire du projet.
4. Je programme en suivant le pas à pas. Je teste souvent avec le drapeau vert.
5. Si je suis bloqué, j'ouvre les coups de pouce dans l'ordre : les questions pour réfléchir, puis les blocs à utiliser, puis le squelette du script où il ne reste que les nombres à trouver. La rubrique « Si ça ne marche pas » aide à corriger les erreurs courantes.
6. Quand le résultat est conforme à la vidéo, je coche « J'ai réussi » et je tente le défi.
7. En fin de séance, je remplis « Où j'en suis » en bas de la page du palier, avec une capture d'écran.

!!! info "Travailler dans Scratch plutôt que dans TurboWarp"
    Le bouton **Télécharger le fichier .sb3** enregistre l'exercice sur l'ordinateur. Dans Scratch (en ligne ou hors ligne) : menu Fichier, puis « Charger depuis votre ordinateur ».

!!! warning "Enregistrer son travail"
    TurboWarp ne garde rien en ligne. Avant de fermer, menu Fichier, puis « Enregistrer sur votre ordinateur » : le fichier .sb3 se range dans le dossier Téléchargements.

## Faire une capture d'écran

| Ordinateur | Raccourci | Ensuite |
|---|---|---|
| Windows | touche Windows + Maj + S | la capture est copiée : Ctrl + V dans la zone prévue |
| Mac | Cmd + Ctrl + Maj + 4 | la capture est copiée : Cmd + V dans la zone prévue |
| Chromebook | Ctrl + Maj + touche fenêtres | choisir le fichier dans Téléchargements |

## Les catégories de blocs

| Catégorie | Couleur | Exemples |
|---|---|---|
| Mouvement | bleu | avancer, tourner, aller à x: y:, glisser |
| Apparence | violet | dire, penser, costume suivant, taille, effets |
| Son | rose | jouer le son, arrêter tous les sons |
| Événements | jaune | quand le drapeau vert est cliqué, envoyer à tous |
| Contrôle | orange | attendre, répéter, si alors, clones |
| Capteurs | bleu clair | touche le bord, demander, réponse, souris pressée |
| Opérateurs | vert | +, -, nombre aléatoire, regrouper, et, ou, non |
| Variables | orange foncé | mettre à, ajouter à, listes |
| Mes blocs | rose foncé | blocs personnalisés (procédures) |
| Stylo, Musique | vert foncé | extensions à ajouter (bouton en bas à gauche) |
