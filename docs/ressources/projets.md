# Projets

Les projets occupent une part importante de l'année, surtout en 3e. Cette page
rassemble les sujets proposés et, quand les élèves l'acceptent, leurs
réalisations.

## Sujets proposés

### Station météo du lycée

Mesurer température, humidité et luminosité dans la cour, enregistrer les
valeurs, produire un graphique hebdomadaire.

*Niveau : 4e ou 3e. Compétences : capteurs, chaîne d'information, traitement de
données.*

### Alerte sismique domestique

Détecter une vibration, déclencher un signal. Le Honduras est en zone sismique,
le sujet parle aux élèves.

*Niveau : 3e. Compétences : capteurs, seuils, fiabilité.*

### Cartographie collaborative du quartier

Compléter OpenStreetMap autour du lycée, avec relevé sur le terrain.

*Niveau : SNT. Compétences : cartographie, données ouvertes.*

### Analyse d'un jeu de données publiques

Choisir un jeu de données honduriennes ou françaises, formuler une question,
produire une réponse chiffrée et un graphique.

*Niveau : SNT. Compétences : données structurées, Python.*

## Méthode

1. Formuler le besoin en une phrase.
2. Écrire le cahier des charges avant de toucher au matériel.
3. Tester par petits morceaux, jamais tout en une fois.
4. Garder trace des essais ratés, ils comptent dans l'évaluation.
