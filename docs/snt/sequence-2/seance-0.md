# Séance 0 — Le fil n'est pas le monde

!!! info "Séquence 2 · séance 0 sur 3 · 55 minutes"

    Sommet et arête, petit monde, modèle économique.

## Ce qu'on a cherché

Avant de mesurer quoi que ce soit, il faut un objet à mesurer. La séance installe le vocabulaire du
graphe, puis suit l'argent depuis le temps passé jusqu'au paiement de l'annonceur.

## Trace écrite

### Les mots de la séance

| Mot | Ce qu'il désigne |
|---|---|
| **Graphe** | Une représentation faite de points reliés par des traits |
| **Sommet** | Un des points du graphe, ici une personne ou un compte |
| **Arête** | Une relation entre deux sommets |
| **Petit monde** | L'idée que deux personnes prises au hasard sont reliées par une chaîne courte |
| **Algorithme de recommandation** | Le programme qui choisit l'ordre des publications affichées |

### La frise à retenir

| Date | Ce qui se passe | Ce que ça change |
|---|---|---|
| 1967 | Expérience de Milgram sur les chaînes de connaissances | L'idée du petit monde entre dans la science |
| 1997 | SixDegrees.com, premier réseau social en ligne | Le graphe des relations devient un service |
| 2004 | Création de Facebook | Le modèle publicitaire s'impose à grande échelle |

Milgram demande à des volontaires de faire parvenir une lettre à un inconnu, de connaissance en
connaissance. Les lettres arrivées ont mis cinq à six étapes. Moins d'un tiers sont arrivées :
l'expérience suggère, elle ne prouve pas.

### La chaîne de l'argent

```
temps passé  ->  données sur l'utilisateur  ->  ciblage publicitaire  ->  l'annonceur paie
```

### Ce que je retiens

Un réseau social se représente par un **graphe** : les comptes sont les sommets, les relations sont
les arêtes. Cette représentation permet de calculer, donc de recommander.

Le service est gratuit parce que l'attention est vendue. Le temps passé produit des données, les
données servent à cibler la publicité, et c'est l'annonceur qui paie. L'utilisateur n'est pas le
client : il fournit ce qui est vendu.

L'algorithme qui classe le fil optimise une **mesure**, le temps passé, et non une valeur. Il n'a
aucune idée de ce qui est vrai, ni de ce qui est bon pour la personne qui regarde.

### Ce que je dois savoir refaire

- Distinguer un sommet d'une arête sur un graphe donné.
- Expliquer en quatre étapes comment une plateforme gratuite gagne de l'argent.
- Dire ce que cherche à maximiser un algorithme de recommandation.

## La question de la séance suivante

Si le réseau est un graphe, alors il se mesure. Qui y occupe la position la plus importante, et
comment le calculer ?
