# Séance 0 : le fil n'est pas le monde

!!! info "Séquence 2 · séance 0 sur 3 · 45 minutes"

    Petit monde, sommet et arête, fil calculé. [Fiche élève en PDF](fiches/snt-seq2-seance0-eleve.pdf)

## Ce qu'on a cherché

Deux personnes ouvrent la même application, au même moment, et ne voient pas la même chose. Avant
de répondre, on remonte l'histoire de l'idée de réseau social, puis on apprend à dessiner un réseau
comme un graphe.

## Trace écrite

À recopier dans le cahier de leçon : les mots de la séance et « ce que je retiens ».

### Les mots de la séance

| Mot | Ce qu'il désigne |
|---|---|
| **Réseau social** | Un service en ligne où chacun déclare des relations avec d'autres comptes |
| **Graphe** | Un ensemble de sommets reliés par des arêtes |
| **Sommet** | Un élément du graphe ; ici, un compte |
| **Arête** | Un lien entre deux sommets ; ici, une relation |
| **Graphe orienté** | Un graphe dont les arêtes ont un sens (une flèche), comme « suivre » |
| **Fil d'actualité** | La liste de contenus choisie et classée par la plateforme, différente pour chaque compte |

### La frise à retenir

| Date | Ce qui se passe | Ce que ça change |
|---|---|---|
| 1929 | Frigyes Karinthy imagine une courte chaîne de connaissances | L'idée du petit monde |
| 1967 | Expérience de Milgram : environ six maillons | Les « six degrés de séparation » |
| 1997 | SixDegrees.com | Le graphe des relations est enregistré par une machine |
| 2006 | Premier fil d'actualité | La plateforme choisit ce que chacun voit |
| 2011 | Étude sur 721 millions de comptes : environ 4,7 étapes | Le petit monde mesuré sur une plateforme |

Beaucoup de lettres de Milgram ne sont jamais arrivées : l'expérience suggère, elle ne prouve pas.

### Sommet, arête, ou ni l'un ni l'autre ?

| Élément | Place dans le graphe |
|---|---|
| Le compte d'un élève, la page d'un club | Sommets |
| Une demande d'ami acceptée | Arête non orientée (un trait) |
| « Suivre » un compte | Arête orientée (une flèche) |
| Le mot de passe, le fil d'actualité | Ni l'un ni l'autre |
| Un « j'aime » | À discuter : ni l'un ni l'autre dans le graphe des personnes, arête vers un contenu si le graphe contient aussi les publications |

### Ce que je retiens

Un réseau social se représente par un **graphe** : les comptes sont des **sommets**, les relations
sont des **arêtes**. Quand la relation a un sens (suivre), le graphe est orienté ; quand elle est
réciproque (être ami), il ne l'est pas. Depuis la fin des années 1990, ce graphe est enregistré par
les plateformes.

L'expérience de Milgram suggère que deux inconnus sont reliés par une chaîne d'environ six
maillons : c'est l'effet « petit monde ».

Le fil d'actualité n'est pas le monde : c'est une **sélection** calculée pour chaque compte par la
plateforme.

### Ce que je dois savoir refaire

- Dire si un élément est un sommet, une arête, ou ni l'un ni l'autre.
- Dessiner une relation orientée (flèche) et une relation réciproque (trait).
- Situer Milgram, SixDegrees.com et le premier fil d'actualité sur une frise.
