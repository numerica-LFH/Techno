## Ce qu'on a cherché

Presque tout le monde emploie « Internet » et « le Web » l'un pour l'autre. La séance sert à
séparer les deux, et à voir lequel est venu en premier.

## Trace écrite

### Les mots de la séance

| Mot | Ce qu'il désigne |
|---|---|
| **Internet** | Le réseau mondial qui transporte des données entre les machines |
| **Le Web** | Un service qui circule sur ce réseau : des documents reliés par des liens |
| **Paquet** | Un morceau numéroté d'un message, réassemblé à l'arrivée |
| **Adresse IP** | L'adresse d'une machine sur le réseau |
| **URL** | L'adresse d'un document sur le Web |
| **Hypertexte** | Le fait de relier des documents entre eux par des liens cliquables |

### La frise à retenir

| Date | Ce qui se passe | Ce que ça change |
|---|---|---|
| 1969 | ARPANET relie quatre universités américaines | Des machines éloignées échangent pour la première fois |
| 1974 | Cerf et Kahn publient les principes de TCP/IP | Le message est coupé en paquets numérotés |
| 1982 | Le Minitel en France | Un réseau peut très bien marcher et rester fermé |
| 1983 | ARPANET bascule sur TCP/IP | Des réseaux séparés se parlent : c'est le réseau des réseaux |
| 1989 | Tim Berners-Lee propose l'hypertexte au CERN | Naissance du Web, vingt ans après le réseau |
| 1991 | Première page web publique, `info.cern.ch` | Le Web sort du laboratoire |
| 30 avril 1993 | Le CERN place le Web dans le domaine public | Gratuit pour tous, le nombre de sites décolle |

### Ce que je retiens

Internet est un réseau : il transporte. Le Web est un service qui circule dessus : il affiche des
documents reliés par des liens. Le réseau a une vingtaine d'années de plus que le service.

Sur Internet, un message n'est pas envoyé d'un bloc. Il est découpé en **paquets** numérotés qui
voyagent séparément et sont réassemblés à l'arrivée. Aucune machine ne connaît le trajet complet :
chaque routeur prend une décision locale, avec sa seule table de routage.

Le Minitel est le contre-exemple de la séance. Tout y passait par un centre, et les services
étaient choisis d'avance. On y consultait, on n'y publiait pas.

### Ce que je dois savoir refaire

- Placer un élément dans la bonne colonne : Internet, le Web, ou ni l'un ni l'autre.
- Justifier ce classement par une seule question : est-ce que ça sert à transporter, ou à
  afficher des documents liés entre eux ?
- Dire lequel des deux est le plus ancien, et de combien.
