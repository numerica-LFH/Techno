# Séquence 3 — Les données structurées

**Seconde · trois séances de 55 minutes**

Un fichier de 200 000 lignes ne se lit pas. Il se trie, se filtre, se croise. La séquence installe
le vocabulaire, puis fait manipuler un jeu de données réel, défauts compris.

!!! abstract "Ce que dit le programme"

    Thème *Les données structurées et leur traitement*, programme de SNT du 22 janvier 2019.

    - Donnée, descripteur, table de données.
    - Formats ouverts, CSV, JSON.
    - Tri, recherche, filtrage, croisement de deux tables.
    - Métadonnées, stockage et centres de données.
