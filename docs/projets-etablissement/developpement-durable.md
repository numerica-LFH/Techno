# Développement durable

## Objet du projet

Mesurer, comprendre et réduire l'empreinte de l'établissement. La technologie
apporte les capteurs et le traitement de données, la SNT apporte l'analyse des
jeux de données et le coût du numérique lui-même.

## Axes de travail

### Mesurer

Installer des capteurs dans les bâtiments : température, luminosité,
consommation électrique. Les données sont enregistrées, puis traitées en classe.

*Lien avec les programmes : chaîne d'information (4e), données structurées (SNT).*

### Comprendre

Analyser les relevés sur une année, repérer les gaspillages, comparer les
bâtiments entre eux.

### Agir

Proposer au chef d'établissement des mesures chiffrées, avec le gain attendu.
Les élèves présentent leurs conclusions devant un public adulte.

## Volet numérique responsable

Le numérique consomme. Un serveur, un centre de données, un téléphone
renouvelé tous les deux ans ont un coût réel. Le projet inclut un travail sur
la durée de vie des équipements du lycée et sur le stockage des fichiers.
