# Évaluations harmonisées : dépôt sur GitHub

Trois lots, un par niveau, chacun sous la limite de 100 fichiers de la page « Upload files ».
Ils ne contiennent que des fichiers modifiés ou nouveaux ; aucun fichier n'est à supprimer pour
que le site fonctionne. `mkdocs.yml` n'est pas modifié.

## Procédure, pour chaque lot (5e, puis 4e, puis 3e)

1. Décompresser le lot sur l'ordinateur.
2. Sur github.com, ouvrir le dépôt numerica-LFH/Techno, à la racine.
3. Add file, puis Upload files.
4. Glisser le dossier `docs` du lot dans la page (le dossier entier, pas son contenu).
5. Message du commit : « Évaluations 5e » (ou 4e, 3e), puis Commit changes.
6. Onglet Actions : attendre que la construction passe au vert avant le lot suivant.

## Contenu

- Lot 5e (68 fichiers), lot 4e (81), lot 3e (83, dont `ressources/accroches.md` et
  `technologie/projet-jardin-sec/telechargements.md`).
- Pour chaque séquence : pages de séance (section « S'évaluer » en bas), index de séquence,
  évaluations de séance, évaluation de fin de séquence, exercices autocorrectifs (ordre des choix
  mélangé). Séquence 2 : fiche HTML et PDF de la séance 3 mises à jour.

## Nettoyage conseillé (facultatif)

Deux dossiers en double se trouvent dans `docs/` et sont publiés comme pages orphelines :
`docs/docs 4/` et `docs/1_a_deposer_dans_docs-technologie/`. Ce sont d'anciennes copies de dépôt.
Pour les retirer : ouvrir le dossier sur github.com, menu « ... » en haut à droite, Delete directory.

## Lot professeur

`evaluations-PROF-ne-pas-publier.zip` : les 20 corrigés (HTML et PDF). Le dépôt GitHub est public :
tout fichier qu'on y dépose se lit sur github.com, même hors de `docs/`. Les corrigés restent donc
sur le poste ou dans un Drive privé, jamais dans le dépôt.
